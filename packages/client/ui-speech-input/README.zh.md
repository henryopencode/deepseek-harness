# `@deepseek-ai/dsh-client-ui-speech-input`

[English](README.md) | 中文

贡献到 `conversation.input.right` 的浏览器麦克风输入。空闲条目是一个麦克风按钮。录音时，控件会用 Codex 风格横条覆盖常驻工具行，同时保留输入框 textarea 与主发送圆钮：左侧取消，中间显示 96 点实时振幅历史，右侧停止。停止后把一段有界录音交给 `speechToTextLocal`；成功时把识别文字追加到最新草稿，绝不自动发送。

控件会在请求麦克风权限前读取权威时长与字节限制，在达到 Host 时长限制时自动停止，区分首次模型准备与普通转写；取消或卸载时会关闭全部媒体轨道和 AudioContext，并把浏览器权限、设备、准入、提供方与传输失败映射成本地化输入框反馈。

## 模型体验

无，因为录音状态和识别文字会留在人类持有的草稿中，直到普通输入框提交它们。

#### KV Cache 影响

无；人类提交后，已接受转写文字的缓存行为与手工输入的文字相同。

## 已知限制与延期工作

- **草稿插入会追加到末尾**：公开输入框 action 接受完整草稿，但不会向同级插件公开 textarea selection。
- **没有局部转写**：本地提供方只会在停止的录音结算后返回。
- **浏览器权限仍是权威**：缺少 `MediaRecorder`、没有可用设备或麦克风权限被拒绝时，无论 Host 是否就绪都不能使用该交互。
